# Project Management Approach

This project will use a hybrid Scrum-Kanban approach.

Development will be organized into small iterations focused on delivering working functionality. Features will be implemented incrementally, starting with a minimum viable product (MVP) and expanding based on future requirements.

Responsibilities will be divided between the developer and AI assistants.

Developer responsibilities:

* Define requirements
* Make architecture decisions
* Review generated code
* Verify business logic
* Approve final implementations

AI responsibilities:

* Generate boilerplate code
* Suggest implementation approaches
* Create documentation drafts
* Assist with debugging
* Generate unit tests

All AI-generated code must be reviewed before being accepted into the project.
