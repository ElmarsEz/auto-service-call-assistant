# Roadmap

## MVP Goal

Develop a basic Car Service Management System that allows users to manage customers, vehicles, and repair orders.

---

## Sprint 1 - Project Setup

Tasks:

* Create repository structure
* Configure Flask project
* Configure SQLite database
* Create basic application layout

Deliverable:

* Running application skeleton

---

## Sprint 2 - Customer Management

Tasks:

* Create customer entity
* Add customer creation form
* Add customer list view
* Add customer editing functionality

Deliverable:

* Customer management module

---

## Sprint 3 - Vehicle Management

Tasks:

* Create vehicle entity
* Link vehicles to customers
* Add vehicle creation form
* Add vehicle list view

Deliverable:

* Vehicle management module

---

## Sprint 4 - Repair Orders

Status: Complete

Tasks:
- Create repair order entity
- Assign vehicle to repair order
- Add repair status tracking
- Add repair order list

Deliverable:
- Repair order management module

Implemented:
- Repair order creation logic
- Factory Method pattern
- Input validation
- Default status assignment
- Module documentation
- Updated architecture diagram

---

## Sprint 5 - Search and Reports

Tasks:

* Search customers
* Search vehicles
* Search repair orders
* Create simple statistics page

Deliverable:

* Search and reporting functionality

---

## MVP Features

Included:

* Customer management
* Vehicle management
* Repair orders
* Status tracking
* Search functionality

Not Included:

* Vehicle specification APIs
* VIN decoding
* SMS notifications
* CRM integrations
* AI recommendations

---

## Future Releases

Potential future improvements:

* Vehicle data lookup API
* VIN decoder integration
* Parts inventory management
* Service history analytics
* AI-assisted repair recommendations
* Appointment scheduling
