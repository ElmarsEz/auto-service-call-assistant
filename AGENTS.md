# AGENTS.md

## Project Overview

Car Service Management System is a web application for managing customers, vehicles, and repair orders in a small automotive workshop.

The system should help service managers:

* Register customers
* Register vehicles
* Create repair orders
* Track repair status
* View repair history
* Search customers and vehicles

## Technology Stack

* Python
* Flask
* SQLite
* HTML/CSS
* Bootstrap

## Coding Standards

* Follow PEP8 style guidelines
* Use meaningful variable and function names
* Keep functions focused on a single responsibility
* Write modular and maintainable code
* Use comments only when necessary

## Restrictions

* Do not introduce unnecessary dependencies
* Do not use external APIs unless specified in roadmap
* Do not modify database schema without documentation update
* Do not remove existing functionality without approval
